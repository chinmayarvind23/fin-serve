# Evaluation artifact location

Raw evaluation requests, answers, suite/grader hashes and reports remain outside the checkout in `resources/fin_serve/evidence/`. Failed output and invalid structured responses are retained. Do not alter expected answers, discard failed cases or replace an old attempt to improve a reported score.

See [evaluation methods](../../docs/evaluation.md) and [recorded results](../../docs/results.md). Correctness, typed baseline parity and exact raw-output agreement have different denominators and acceptance rules.
