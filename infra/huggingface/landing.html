BUILT FOR MODEL-BACKED APPLICATIONS

From request to controlled release.

Stream text and image answers

FastAPI and engine adapters provide bounded streaming, validated image input, and cancellation ownership.

Route work deliberately

Ray Serve selects eligible engines. Redis quotas and admission limits bound work before GPU execution.

Control model changes

Airflow coordinates model preparation and gated deployment. Revision checks and durable state protect rollback.

SERVICE OWNERSHIP

Each component has a defined job.

Bun edge → FastAPI → Ray Serve → model engine

Visual jobs use a separate gRPC JAX/Flax reference worker. The explorer reads registered runs through GraphQL. SQL and immutable artifacts hold release state; MLflow receives operator-controlled exports.
