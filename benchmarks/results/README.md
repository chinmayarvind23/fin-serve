# Benchmark artifact location

Generated benchmark evidence belongs outside this repository under `resources/fin_serve/evidence/`. Do not write raw prompts, runtime credentials, databases or failed-run replacements here. Each attempt has a fresh directory and retains its original source/image declarations.

The repository publishes [result summaries](../../docs/results.md), [aggregate figures](../../docs/assets/) and reusable audit scripts. Those summaries link measurements to their retained private run IDs and state failed gates explicitly.
